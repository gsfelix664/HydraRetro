=== HydraRetro - Nintendo Switch (Ryujinx Portable) ===

1. Coloque o executável do Ryujinx ("Ryujinx.exe" ou "Ryujinx.Ava.exe") nesta pasta.
2. A pasta "portable\" garante que nenhum arquivo do emulador seja salvo fora desta pasta (100% isolado).
3. Coloque suas chaves "prod.keys" e "title.keys" em:
   emulators/ryujinx/portable/system/prod.keys
   (ou no diretório geral BIOS/switch/)
4. Abra o Ryujinx uma vez para instalar o Firmware oficial:
   Vá em: Tools -> Install Firmware -> Install a firmware from XCI or ZIP
5. Coloque suas ROMs (.nsp ou .xci) na pasta:
   ROMS/SWITCH/
   (ou aponte a pasta externa, como D:\games\Switch, na aba de Configurações do HydraRetro).
